# UNP_ML_REGRESSION_PROJECT_STEEL_INDUSTRY_ENERGY_CONSUMPTION_PREDICTION_USING_PYTHON


I did this project in collaboration with United Network Of Professionals (UNP) on Steel Industry Energy Consumption Using Python.This is a group project completed as part of our internship.

This project focuses on predicting electricity consumption in the steel industry using machine learning techniques. It uses a dataset containing 35,040 records collected at 15-minute intervals. The main objective is to estimate energy usage based on different electrical and operational factors. Data cleaning and preprocessing are carried out to prepare the dataset for analysis. Exploratory Data Analysis is performed to understand energy consumption patterns and relationships between features. Seven regression algorithms are implemented and compared using different train-test splits. An Artificial Neural Network (ANN) is also developed and tested with different configurations. Model performance is evaluated using MAE, RMSE, MAPE and R² scores. Gradient Boosting performs best among the traditional regression models, while the ANN achieves a slightly higher R² score. The project aims to support better energy prediction and consumption management in steel industries.

Technologies Used: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, TensorFlow and Keras.
